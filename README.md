# 어디갈래

> 목적지를 숨긴 채 코스를 만들고, 도착해서 정차(P)하면 장소를 공개하는 Pleos Connect 차량용 앱. (팀 **가보자**)

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다.

## 한 줄 소개

"4시간 안에, 10만 원으로, 맛있는 점심 포함해서 아무 데나 데려가 줘" 한마디로 코스를 만들고, 차의 배터리·연료와 주행 상태에 맞춰 안내하는 즉흥 드라이브 앱입니다.

## 차량 특화 요소

- **정차(P)일 때만 화면 조작**: 주행 중에는 음성 안내와 음성 명령 중심입니다. 도착해도 P가 되기 전에는 장소를 알려 주지 않습니다.
- **차량 데이터 기반 코스**: 배터리 잔량(`EvBattery`), 연료(`Fuel`), 주행가능거리(`Odometer`), 기어(`Gear`)를 Vehicle SDK로 읽어 갈 수 있는 거리를 계산합니다.
- **전기차 / 내연기관 모두 지원**: 잔량 20% 이하에서 충전소(주유소) 안내를 제안하고, 10% 이하에서는 다시 강하게 알립니다. 충전 중·주유 중 화면과 근처 둘러보기를 제공합니다.
- **보수적인 시간 계획**: 이동 시간 +15%, 장소마다 주차·이동 10분, 최소 체류 30분, 전체 시간의 10%(최소 15분)는 예비로 남깁니다.
- **경로 변경(음성 명령)**: 다음 장소 바꾸기, 건너뛰기, 쉬어 가기, 실내로, 귀가, 충전소 안내. 정차 중과 주행 중 모두 가능합니다.
- **장소 이야기**: 도착한 곳의 사진·소개·이용시간과 근처 식당·카페·명소(대표 메뉴 포함)를 필요한 만큼만 펼쳐 볼 수 있게 접는 구조로 보여 줍니다.

## 실행 방법

1. Pleos Connect 에뮬레이터를 켭니다(Android Studio, Device Manager).
2. APK를 설치합니다.
   ```
   adb install -r apk/가보자_어디갈래_release.apk
   ```
3. 앱 목록에서 **어디갈래**를 실행합니다.
4. 시간·분위기를 고르거나 문장을 입력하고 **아무 데나 데려가 줘**를 누릅니다.

에뮬레이터에는 실제 도로가 없어서, 앱 상단에 **데모 도구**가 기본으로 열려 있습니다(접을 수도 있습니다).
- 기어: 차량값 / P / D (D로 두면 시간이 흘러 이동이 진행됩니다)
- 시간 배속: x1 / x100 / x400
- 차량: 전기차 / 내연기관, 배터리(연료) -10%, 도착 처리
- 기어가 "차량값"이면 Pleos Connect 버추얼 콘솔에서 바꾼 기어·배터리를 앱이 따라가도록 만들었습니다(콘솔로는 아직 직접 시험하지 못했습니다).

## 사용한 Pleos SDK

| SDK | 상태 |
|---|---|
| Vehicle SDK 2.3.2 | **사용 중**: 배터리 SoC, 연료, 주행가능거리(미터), 기어 |
| NaviHelper, FusedLocation, TextToSpeech, SpeechToText | 의존성만 포함, **아직 연동하지 않음** (길 안내·도착 감지·음성은 시뮬레이션으로 대체) |

## 데이터와 출처

앱은 **인터넷과 API 키 없이** 동작하도록 데이터를 앱 안에 포함했습니다(`app/src/main/assets`).

- 장소 소개·이용시간·사진·주변 식당/카페/명소: 한국관광공사 TourAPI (공공누리, 사진마다 출처와 유형 표시)
- 일부 사진·설명·대표 메뉴 예시 사진: Wikimedia Commons / 위키백과 (사진마다 작성자와 라이선스 표시)
- 도로 거리·시간: OSRM으로 미리 계산한 값
- 식당의 음식 사진은 **대표 메뉴 예시 사진**이며 해당 식당의 사진이 아닙니다.
- 충전소(휴게소) 주변 장소와 충전 요금 단가는 샘플 값입니다(화면에 표시).

단위 테스트 37개가 코스 생성, 경로 변경, 충전·경고 흐름, 데이터 형식을 검사합니다.

## 알려진 한계

- 지도와 길 안내는 차량 내비게이션(NaviHelper)에 맡기는 구조이며, 이 버전은 연동 전입니다.
- 도착 감지(FusedLocation)와 음성 입력·안내(STT/TTS)는 연동 전이고, 데모 도구로 대체합니다.
- 장소는 수도권·강원 일부 9곳으로 한정한 시범 데이터입니다.

## 시연 순서 (에뮬레이터)

1. 조건을 고르고 **아무 데나 데려가 줘**
2. 데모 도구에서 기어 **D**, 배속 **x100** → 이동이 진행되고 배터리가 줄어듭니다
3. 도착하면 기어를 **P**로 → 장소 사진·소개·근처 식당/카페/명소가 공개됩니다
4. **배터리 -10%**를 눌러 20% 아래로 내리고 D로 두면 충전소 안내 알림이 뜹니다
