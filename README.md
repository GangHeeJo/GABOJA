# 어디갈래

> 시간과 예산 등 간단한 정보만 수집하고 차량 상태와 실시간 상황을 읽어 드라이브 코스를 짜는 즉흥 드라이브 내비게이션 앱

현대자동차그룹 차량용 앱 개발 공모전 출품작 · 팀 **가보자**

## 컨셉

- **가게가 아니라 코스가 주인공**: 달리는 길과 풍경을 코스의 뼈대로 두고, 식당·카페는 그 위에 얹는 교체 가능한 경유지로 다룹니다.
- **공개의 순간**: 출발 전에는 힌트 한 줄만 주고, 도착해서 **정차(P)하면** 장소와 할 일을 공개합니다. 공개는 구간마다 반복됩니다.
- **주행 중에는 음성 중심, 상세 화면은 정차 상태에서만** 보여 줍니다.

## 기능과 구현 현황

기획서의 핵심 기능 기준으로, 이 저장소의 **현재 버전(1차 제출)** 이 어디까지 되어 있는지 적었습니다.

| 기획서 기능 | 현재 상태 |
|---|---|
| ① 한마디 코스 생성 | **부분**: "4시간 안에, 10만 원 이하로, 점심 포함해서 아무 데나" 같은 문장을 조건으로 해석합니다. 입력은 음성이 아니라 **텍스트 입력**입니다(STT 미연동). |
| ② 구간별 목적지 공개 | **구현**: 전체 경로를 숨기고 힌트 한 줄만 보여 주며, 도착 후 P에서 장소를 공개합니다. 도착은 시뮬레이션입니다(FusedLocation 미연동). |
| ③ 차량 상태 기반 현실성 검토 | **부분**: 배터리(전기차)·연료(내연기관) 잔량으로 갈 수 있는 범위를 계산해 왕복 가능한 코스만 만듭니다. 환산 계수(전기 5km/%, 내연 6km/%)를 쓰고, 실제 전비·연비는 아직 반영하지 않습니다. 충전·주유 정차를 코스에 끼워 넣고 충전 중 화면을 제공합니다. |
| ④ 실시간 코스 재구성 | **구현**: 다음 장소 바꾸기, 건너뛰기, 쉬어 가기, 실내로, 귀가, 충전소(주유소) 안내를 정차 중·주행 중 모두 할 수 있습니다. 입력은 음성 명령 **버튼**입니다(STT 미연동). 잔량 20% 이하에서 충전소 안내를 제안하고 10% 이하에서 다시 강하게 알립니다. 비·정체·휴무 같은 외부 상황 감지는 아직 없습니다. |
| ⑤ 여행 기록과 학습 | **부분**: 다녀온 곳과 만족도(좋았어요/별로예요), 총 주행거리·시간을 기록 화면으로 보여 줍니다. 만족도를 다음 코스에 반영하는 학습은 아직 없습니다. |

추가로 구현한 것
- **보수적인 시간 계획**: 이동 시간 +15%, 장소마다 주차·이동 10분, 최소 체류 30분, 전체 시간의 10%(최소 15분)는 예비로 남깁니다. 조건에 맞는 코스가 없으면 어떤 조건이 막았는지(시간·거리·배터리·예산) 알려 줍니다.
- **장소 이야기**: 도착한 곳의 사진·소개·이용시간과 근처 식당·카페·명소(대표 메뉴 포함)를 보여 줍니다. 한 화면에 정보가 몰리지 않도록 눌러서 펼치는 접힘 구조로 만들었습니다.

## 사용한 Pleos SDK

기획서의 SDK 사용 계획 대비 현황입니다.

| SDK | 기획서의 용도 | 현재 상태 |
|---|---|---|
| Vehicle - EvBattery | 배터리 충전량 조회 | **사용 중** (SoC) |
| Vehicle - Fuel | 연료 잔량 조회 | **사용 중** (내연기관일 때). 전기차 에뮬레이터는 지원하지 않는다는 응답을 줍니다. |
| Vehicle - Odometer | 주행거리·주행가능거리 | **읽기만** 함: 주행가능거리가 미터 단위로 오며(에뮬레이터 500000 → 500km) 화면 계산에는 아직 쓰지 않습니다. |
| Vehicle - Gear | (기획서: Brake/DrivingMode로 정차 판단) | **사용 중**: 기어 P/D로 정차 여부를 판단합니다. DrivingMode는 에뮬레이터에서 지원하지 않는다는 응답이었습니다. |
| FusedLocation | 도착 감지(근접 알림) | **미연동**: 도착은 시뮬레이션 |
| NaviHelper | 목적지 설정·재탐색 | **미연동**: 길 안내와 지도는 차량 내비게이션에 맡기는 구조 |
| SpeechToText / TextToSpeech | 음성 입력·안내 | **미연동**: 텍스트 입력과 화면 문구로 대체 |

코스 서버와 생성형 AI는 사용하지 않았습니다. 현재는 앱 안의 규칙 기반 코스 생성기가 미리 검수한 장소 9곳(수도권·강원) 안에서 조건에 맞는 코스를 고릅니다.

## 실행 방법

1. Pleos Connect 에뮬레이터를 켭니다(Android Studio, Device Manager).
2. APK를 설치합니다.
   ```
   adb install -r apk/가보자_어디갈래_release.apk
   ```
3. 앱 목록에서 **어디갈래**를 실행합니다.
4. 시간·분위기를 고르거나 문장을 입력하고 **아무 데나 데려가 줘**를 누릅니다.

에뮬레이터에는 실제 도로가 없어서, 앱 상단에 **데모 도구**가 기본으로 열려 있습니다(접을 수도 있습니다).
- 기어: 차량값 / P / D (D로 두면 시간이 흘러 이동이 진행됩니다)
- 시간 배속: x1 / x100 / x400
- 차량: 전기차 / 내연기관, 배터리(연료) -10%, 도착 처리
- 기어가 "차량값"이면 Pleos Connect 버추얼 콘솔에서 바꾼 기어·배터리를 앱이 따라가도록 만들었습니다(콘솔로는 아직 직접 시험하지 못했습니다).

### 시연 순서

1. 조건을 고르고 **아무 데나 데려가 줘**
2. 데모 도구에서 기어 **D**, 배속 **x100** → 이동이 진행되고 배터리가 줄어듭니다
3. 도착하면 기어를 **P**로 → 장소 사진·소개·근처 식당/카페/명소가 공개됩니다
4. **배터리 -10%**를 눌러 20% 아래로 내리고 D로 두면 충전소 안내 알림이 뜹니다

## 데이터와 출처

앱은 **인터넷과 API 키 없이** 동작하도록 데이터를 앱 안에 포함했습니다(`app/src/main/assets`).

- 장소 소개·이용시간·사진·주변 식당/카페/명소: 한국관광공사 TourAPI (공공누리, 사진마다 출처와 유형 표시)
- 일부 사진·설명·대표 메뉴 예시 사진: Wikimedia Commons / 위키백과 (사진마다 작성자와 라이선스 표시)
- 도로 거리·시간: OSRM으로 미리 계산한 값
- 식당의 음식 사진은 **대표 메뉴 예시 사진**이며 해당 식당의 사진이 아닙니다.
- 충전소(휴게소) 주변 장소와 충전 요금 단가는 샘플 값입니다(화면에 표시).

단위 테스트 37개가 코스 생성, 경로 변경, 충전·경고 흐름, 데이터 형식을 검사합니다. 제출용 APK에는 폰트 파일을 포함하지 않았습니다(시스템 글꼴로 표시됩니다).

## 알려진 한계와 다음 단계

기획서의 일정에 따라 2차 PT 심사 전까지 아래를 연동할 계획입니다.

- FusedLocation 근접 알림으로 도착 감지, NaviHelper로 목적지 전달·재탐색
- SpeechToText·TextToSpeech로 음성 입력과 안내
- 앱 안에서 이동 경로를 지도로 그리기(현재는 코스 진행 목록만 표시)
- 만족도·방문 기록을 다음 코스에 반영하는 학습, 영업 여부·날씨 확인
- 실제 전비·연비 반영, Odometer 주행가능거리를 계산에 사용
- 장소는 현재 9곳으로 한정한 시범 데이터입니다.
